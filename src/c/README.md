# Implementación C

## Requisitos

- Compilador C11 (p. ej. `gcc`)

## Compilar y ejecutar

```bash
gcc -std=c11 -Wall -Wextra -O2 -o caida main.c -lm
./caida
```

En Windows (PowerShell), el ejecutable será `caida.exe`.
