# Implementación Pascal (Free Pascal)

Misma estructura que la referencia C / contrato NS.

## Requisitos

- Free Pascal (`fpc`)

## Compilar y ejecutar

```bash
fpc -O2 main.pas
./main
```

En Windows (PowerShell):

```powershell
fpc -O2 main.pas
.\main.exe
```

## Uso

Igual que C: modo `1` (beta dado) o `2` (buscar beta). Caso enunciado: `2` / `80` / `50` / `1500`.
